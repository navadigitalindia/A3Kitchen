# A3 Kitchen — Digital Restaurant Menu

A premium, mobile-first digital restaurant menu web application designed for table QR-code access. Customers can scan the table QR code, browse authentic dishes across all categories, inspect ingredients and descriptions, and reserve a table.

## Key Features

- **True QR Menu Experience**: Streamlined for dine-in guests without app downloads, accounts, carts, or checkout friction.
- **Refined Color Architecture**: Balanced harmony between Deep Navy (`#071726`), Warm Cream (`#faf7f2`), Ivory, and subtle Champagne Gold accents.
- **Strict Equal-Size Food Cards**: Standardized card height, uniform image aspect ratios, clamped 2-line descriptions, and aligned price typography to prevent layout shifts.
- **Clean Pill/Tab Navigation**: Category filters (`All`, `Veg`, `Non-Veg`, `Starters`, `Main Course`, `Biryani`, `Chinese`, `Beverages`, `Desserts`) with horizontal scrolling on mobile.
- **Authentic Dietary Indicators**: Standard green and red indicators for Vegetarian and Non-Vegetarian items (zero emojis).
- **Food Details Modal**: Lightweight modal presenting full dish photography, dietary classification, expanded description, and pricing.
- **Table Reservation Modal**: Clean reservation request form with name, phone number, date, time, guest count, and special requests.
- **Responsive Layout**: Designed mobile-first and tested for smooth viewing across smartphones (320px–430px), tablets (768px–820px), and desktops.

## Tech Stack

- **HTML5**: Semantic, accessible markup with ARIA roles and labels.
- **Vanilla CSS**: Custom property design tokens, responsive CSS Grid and Flexbox, line clamping.
- **Vanilla JavaScript**: Pure JS state management for category filtering, modal interactions, mobile drawer, and navigation scrollspy.
